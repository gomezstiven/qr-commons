# ADR-0002 — Apache License 2.0

Status: **Accepted**  
Date: **2026-09-13**

## Context

The project is intended for broad personal, institutional, and commercial adoption, including self-hosting, redistribution, incorporation into other products, and downstream modification.

A copyleft requirement is not necessary to protect the intended economic boundary because the project's defensible value is not based on restricting static QR generation.

## Decision

License QR Commons under the **Apache License, Version 2.0** (`Apache-2.0`).

## Rationale

Apache-2.0 is permissive while providing explicit copyright and patent-license terms for contributors and downstream users. This supports low-friction adoption without requiring derivative software to adopt the same license.

## Consequences

- commercial and proprietary downstream use is allowed subject to the license terms;
- modifications do not have to be contributed back;
- contributors provide the patent license described by Apache-2.0 for applicable contributed patent claims;
- the project should not add a separate `NOTICE` file unless actual attribution notices make one useful, avoiding unnecessary redistribution obligations.
